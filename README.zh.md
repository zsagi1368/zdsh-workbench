# zdsh-workbench（中文）

zDSH 工作台 —— 为 DSH（deepseek-harness）打造的 IDE 级停靠工作区插件：文件 / 编辑器 / 终端 / Git / 任务 / 浏览 / 侧聊一屏直达，并向所有插件开放面板注册表服务。

**净室独立开发**：功能思想参考社区实践，代码、API 形状与资源全部原创。

## 里程碑

M1 外壳骨架 → M2 文件工作台 → M3 终端 → M4 Git 中心 → M5 任务中心 → M6 浏览+侧聊 → M7 打磨 → M8 发布。当前进度见 `docs/PLAN.md`。

## 开发

```sh
pnpm install
pnpm typecheck && pnpm build && pnpm test
```
